📖 Diccionario de Términos Meow CF

📌 1. Sistemas Operativos Objetivo

🤖 Android (APK / PWA)

Configuración estándar para generar un archivo instalable en Android (.apk/.aab) usando herramientas como Bubblewrap, PWABuilder o Capacitor.

🍎 iOS (Safari WebApp)

Ajustes específicos para Safari Mobile en iPhone/iPad, activando el modo pantalla completa nativo de iOS y el icono en la pantalla de inicio.

🚀 Universal

Genera la lista completa de parámetros soportados globalmente por Android, iOS y navegadores de escritorio al mismo tiempo.

📝 2. Datos Generales de la WebApp

📛 Nombre de la App (`name`)

El nombre completo oficial de tu aplicación web tal como aparecerá en la tienda de aplicaciones o en los instaladores.

🏷 Nombre Corto (`short_name`)

Nombre abreviado que se muestra debajo del icono en la pantalla de inicio de los teléfonos móviles cuando el espacio es reducido.

💬 Descripción (`description`)

Texto explicativo breve que describe la función principal de tu aplicación para navegadores y compiladores.

🚀 Start URL (`start_url`)

La página inicial que se cargará automáticamente cuando el usuario abra la app compilada o el icono instalado (Ejemplo: `./index.html` o `/`).

🌐 Scope / Alcance (`scope`)

Define el conjunto de URLs o directorio al que está restringida la app web. Si el usuario navega fuera de este alcance, se abrirá un navegador normal.

🔢 Versión (`version`)

Número de versión del paquete (ej. `1.0.0`) necesario para gestionar actualizaciones cuando compiles la APK.

🎨 3. Apariencia y Comportamiento

📱 Modo de Pantalla (`display`)

Standalone: Oculta la barra del navegador para que parezca una app nativa.
Fullscreen: Oculta también la barra de estado del sistema (batería, hora).

🔄 Orientación (`orientation`)

Fija si la app debe mantenerse en formato vertical (Portrait), horizontal (Landscape) o adaptarse a la rotación del teléfono (Any).

🎨 Theme Color (`theme_color`)

El color que adoptará la barra de estado superior del sistema operativo y del navegador al abrir la app.

🖼 Background Color (`background_color`)

Color de fondo que se muestra mientras se carga la app antes de desplegar el contenido web (Pantalla de carga / Splash Screen).

🖼 Ruta del Icono (`icons`)

La ubicación en tu servidor o proyecto donde está guardada la imagen del icono oficial de tu app (recomendado formato PNG de 512x512 px).
