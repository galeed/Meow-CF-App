🍏 Service Worker (`sw.js`)

Script en JavaScript que se ejecuta en segundo plano en iOS Safari. Actúa como un proxy de red programable: intercepta solicitudes HTTP/HTTPS y decide si entrega datos guardados localmente en la caché del iPhone o si consulta a internet.

📦 Precaching / Pre-caché Inicial

Proceso ejecutado durante la fase de instalación del Service Worker donde se descargan y guardan automáticamente los archivos esenciales (HTML, CSS, JS, fuentes e iconos). Esto garantiza que la estructura básica de la app esté lista incluso antes del primer uso sin conexión.

📥 Estrategia: Cache First (Caché Primero)

Función: Prioriza la memoria local del iPhone. Busca el recurso en la caché y lo entrega de forma inmediata. Si no existe en la caché, realiza la petición a internet y guarda una copia local.
Uso ideal: Aplicaciones completamente offline, juegos web, herramientas de utilidad, reproductores locales y recursos estáticos (CSS, imágenes, JS).

🌐 Estrategia: Network First (Red Primero)

Función: Intenta obtener siempre la versión más reciente desde internet. Si la conexión falla o el usuario está fuera de línea, utiliza automáticamente la copia guardada en la caché local como respaldo (fallback).
Uso ideal: Periódicos, blogs, feeds de noticias y plataformas donde los datos cambian constantemente pero se desea mantener acceso sin conexión.

⚡ Estrategia: Stale-While-Revalidate

Función: Entrega instantáneamente la versión guardada en la caché local para una carga ultrarrápida, mientras en segundo plano realiza una petición a la red para actualizar la caché con la última versión disponible para la siguiente sesión.
Uso ideal: Redes sociales, dashboards, listas de tareas o apps con actualizaciones frecuentes donde la velocidad de inicio es crucial.

📲 Registro e Inscripción SW

Fragmento de código JavaScript que se añade al `index.html`. Notifica a Safari que debe activar `sw.js` en segundo plano cuando el usuario pulsa "Añadir a la pantalla de inicio" en su iPhone o iPad.

⚡ Motores de Compilación Soportados

⚡ Capacitor CLI (Ionic)

El motor nativo moderno preferido para envolver proyectos web en aplicaciones Android e iOS nativas completas, ofreciendo máxima compatibilidad con plugins de hardware.

🤖 Google Bubblewrap CLI

Herramienta oficial de Google que transforma una PWA en un paquete Android Trusted Web Activity (TWA) ligero y de alto rendimiento.

🌐 Microsoft PWABuilder

Plataforma impulsada por Microsoft para empaquetar aplicaciones web progresivas en tiendas de aplicaciones como Google Play Store y Microsoft Store.

📝 Datos y Parámetros

🛠 GitHub Actions Workflow (`.github/workflows/*.yml`)

El script en YAML que se sube a tu repositorio para que los servidores de GitHub instalen el SDK de Android, compilen tu APK en segundo plano y te permitan descargar el archivo ejecutable listo.

⚙️ Capacitor Config (`capacitor.config.json`)

Archivo de configuración JSON que indica a Capacitor el App ID nativo (ej. `com.meowapp.app`) y la ubicación de tus archivos HTML locales.
