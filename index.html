Motores de Compilación

⚡ Capacitor CLI

Herramienta moderna (evolución de Cordova) creada por Ionic. Te permite empaquetar web apps como apps nativas de Android/iOS con acceso a plugins de hardware. Muy recomendado para proyectos complejos.

🌍 Bubblewrap (TWA)

Herramienta oficial de Google para crear Trusted Web Activities. Empaqueta tu PWA (necesita estar hosteada con HTTPS) dentro de un APK muy ligero que corre en Chrome nativo.

🛠 PWABuilder

Plataforma de Microsoft que analiza tu URL y empaqueta la app para tiendas (Google Play, Microsoft Store). Genera código TWA por detrás para Android.

Estrategias Offline (Service Worker)

📦 Cache First

El SW busca el recurso primero en la caché local. Si está, lo carga (instantáneo y funciona offline). Si no, va a la red. Ideal para imágenes, CSS, JS que no cambian seguido.

🌐 Network First

El SW intenta descargar el recurso de internet. Si falla (estás offline), recurre a la caché. Ideal para APIs o datos dinámicos que necesitan estar frescos.

🔄 Stale-While-Revalidate

Muestra instantáneamente la versión de la caché, PERO en segundo plano va a la red por la versión nueva y actualiza la caché silenciosamente. Lo mejor de ambos mundos.
